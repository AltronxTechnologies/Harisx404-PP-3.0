Expected: owner-saved order and new-first rank persist; actual public page uses newest-first fallback and the Admin order control cannot be enabled for this target. **Task P-01:** after owner approval, verify backup/restore on a separate clone, inspect effective catalog and prior migration order, test the additive migration, uniqueness/new-first/backfill and rollback, then apply only through the approved rollout; verify owner/non-owner Admin reorder/save/reopen, concurrent stale edits, new publication and public cache. Risk: migration updates row revisions and may conflict with open editors; stop/restore or forward-fix on mismatch. **Status: BLOCKED, no SQL executed.**

**PI-02 - Confirmed interaction defect, P2, locked index.** Rapid Search + tag selection loses the tag: `ProjectsIndex.tsx:111-148` schedules a search replacement with a captured `searchParams` snapshot; tag pushes in between. Four isolated sequences distinguish successful single actions from failing combined actions. Expected final URL/search/chip/results to represent both intentions. **Task P-02:** request explicit owner unlock of `ProjectsIndex.tsx`; make pending search synchronization merge with the latest filter intent rather than a stale URL and cancel/serialize obsolete timers when tag/page changes.
