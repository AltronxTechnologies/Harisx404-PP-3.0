## Scope And Evidence Boundary

- `app/blog/page.tsx` renders the hero, category/search toolbar, featured post, grid, empty states and desktop/compact pagination from `app/blog/data.ts`. That source loads published posts no later than the current time, omits locally marked drafts, enriches categories and descriptions, and optionally adds reaction summaries; it is cached for 60 seconds (reactions for 30 seconds). `BlogFilterBar.tsx` manages viewport-specific page sizes, URL intent, search debounce and history. `BlogGridCard.tsx` and `FeaturedBlogCard.tsx` render the approved cards. `app/blog/loading.tsx` provides an index-shaped skeleton and `app/blog/error.tsx` provides Retry/Home. Root layout supplies Navbar/Footer, canonical base and shared CTA. Admin publication, featured RPC, tags and reaction data are connected dependencies, not proven by source alone.
- Local Docker `web` served `http://localhost:3000/blog`; the Alloy preview at `http://localhost:8080/blog` showed ten published articles at this checkpoint, seven on compact page one and three on compact page two. Read-only Chromium/browser checks used the current collection, not synthetic owner mutation. Dark desktop/390px viewport screenshots were saved outside the repository at `/tmp/playwright/-tmp-opencode-blog-index-desktop.png` and `/tmp/playwright/-tmp-opencode-blog-index-mobile.png`. Another date, record count, host or theme may produce different content. No real phone/tablet or screen reader was available.
