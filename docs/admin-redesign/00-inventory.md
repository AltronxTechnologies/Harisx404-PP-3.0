# Admin Redesign Inventory

Status legend: **source-confirmed** = present in the current worktree; **observed** = supplied HTTP/browser evidence (role specified); **unverified** = not exercised for that workflow; **blocked** = requires owner approval or a safe environment. Historical observations below predate some Admin changes; use `06-validation-log.md` for the latest evidence. This is not a production sign-off.

## Application map

- **Source-confirmed; browser chrome observed:** `package.json` uses Next 15 (`^15.5.26`), React and Tailwind. `app/layout.tsx` wraps all routes with public Navbar, side rails, Footer, theme provider, chatbot and WebSite JSON-LD. `app/admin/layout.tsx` applies Admin-only visual isolation, noindex and no canonical. Public chrome remains mounted but hidden on Admin; locked public root was not edited.
- **Source-confirmed; limited owner render observed:** `app/admin/(dashboard)/layout.tsx` checks `getUser()` and normalized `ADMIN_EMAIL`, redirects anonymous users to `/admin/login` and non-admin users to `/`, then renders `Sidebar` plus a content grid. It uses local `#F6F7F9`/`#10131A` surfaces and now sets `minWidth: 0` and a `minmax(0, 1fr)` content track. `middleware.ts` also redirects protected `/admin*` routes, except `/admin/login`; middleware is not the API authorization boundary.
- **Source-confirmed; earlier mobile owner browser sampled:** `app/components/admin/Sidebar.tsx` has desktop fixed rail and mobile dialog drawer with Escape/Tab handling, background inertness and sign out. Current destinations: Dashboard, Analytics, Blogs, Projects, Resume, Buildlog, Community Wall, Testimonials, FAQs, Experience, Certifications, Media, About, System Logs, Settings. The earlier 390px drawer check (when Changelogs was still linked) found 16 links with 44px targets, one active `aria-current="page"`, and focus restoration; the current source has 15 links and needs remeasurement.
- **Source-confirmed; owner dashboard sampled:** `/admin` shows six stat cards (blog total/live/draft, projects, article views, reactions), quick actions and recent blog/project lists. Dashboard and Projects list check Admin before service-role access. Query errors show unavailable/error rather than zero/empty. Dashboard has Admin-only min-width/minmax containment; stats are 2 columns at `md`, 3 at `xl`; Quick Actions are one column on mobile, two at `lg`; main panels split at `xl`. 320/390/640 remeasurement found no uncontained overflow; dark 390/1440 visual review found no gross clipping. Counts, drafts, interactions and other themes remain unverified.
- **Source-confirmed; anonymous redirect observed:** `app/admin/(dashboard)/{media,about,settings}/page.tsx` receives the Sidebar/content wrapper at unchanged URLs. Anonymous visits return 307 to `/admin/login`. `/admin/login` remains outside `(dashboard)`; the inherited public chrome is hidden only on Admin routes. Other authenticated page layouts are not fully reviewed.
