## Executive Overview

**TourMate Malakand** is an end-to-end regional tourism management and exploration ecosystem developed to streamline travel across the historical Malakand division in Khyber Pakhtunkhwa, Pakistan. Built as a production-grade MERN application, it centralizes verified travel spots, localized emergency response contacts, real-time meteorological forecasts, and authenticated traveler reviews into a unified, responsive interface.

The application addresses critical information bottlenecks faced by travelers navigating mountain valleys: outdated road statuses, unverified emergency services, and inaccurate geographical markers.

### Frontend Engineering
* **Framework**: React 18 initialized via Vite for lightning-fast HMR and optimized tree-shaken production bundles.
* **Geospatial Engine**: Mapbox GL JS with custom valley markers, bounding-box constraints, and interactive fly-to animations on spot selection.
* **Client Performance**: Client-side image compression converts 5MB+ smartphone captures into compressed WebP payloads before transmission, ensuring reliable uploads even on high-latency 3G valley connections.

### Backend & API Architecture
* **Server**: Node.js 20 LTS running Express 5 with pure ES Modules (`type: "module"`).
* **Database Modeling**: MongoDB Atlas via Mongoose with strict schema validation, compound indexes for rapid query filtering, and population hooks for spot-review relationships.
* **API Documentation**: Automated Swagger/OpenAPI 3.0 specification generated from JSDoc annotations at `/api-docs`.

## Key Features & Capabilities

1. **Interactive Spatial Discovery**: Browse mountain passes, waterfalls, heritage sites, and alpine meadows with exact latitude/longitude coordinates and custom map layers.
2. **Emergency SOS Directory**: Instant direct-dial access to regional hospitals, rescue 1122 services, tourist police posts, and local district administrations.
3. **Live Atmospheric Conditions**: Real-time temperature, humidity, and weather conditions retrieved dynamically via OpenWeatherMap API for each listed destination.
4. **Curated Destination Management**: Role-based administrative dashboard to approve new submissions, verify photos, inspect analytics, and audit user feedback.
5. **Secure Authentication & RBAC**: JWT authorization tokens stored in secure cookies, password hashing with salt rounds via bcryptjs, and role-based endpoint protection.

---

## Security & Reliability Engineering

* **NoSQL Injection Defense**: Sanitization middleware strips dangerous MongoDB operators (`$gt`, `$where`, `$regex`) from all incoming request bodies and query parameters.
* **Rate Limiting**: Tiered request caps protect authentication endpoints from brute-force password guessing.
* **HTTP Security Headers**: Helmet configuration sets strict CSP directives, disables `X-Powered-By`, and enforces frame guard protections against clickjacking.
* **Structured Telemetry**: Winston logger outputs timestamped, categorized application events to rolling log files for rapid incident investigation.
