key_decisions: |
  1. Async Python Pipeline (FastAPI + aiofiles): Suricata produces relentless JSON log writes. Using synchronous file reading would block the event loop. Implemented non-blocking aiofiles tailing paired with an async generator pipeline that ingests, parses, and broadcasts events in under 2ms.
  2. In-Memory Sliding Window Deduplication: Port scans, DoS attacks, and brute-force bursts generate thousands of identical signature hits in seconds. Implemented an in-memory ring buffer tracking (src_ip, signature_id, timestamp_window) that collapses redundant flood alerts before persisting to database storage.
  3. WebSocket Broadcast Hub over REST Polling: Polling a REST endpoint every second consumes substantial network overhead and introduces latency. Built a pub/sub WebSocket connection manager in FastAPI that fans out parsed alerts to all connected SOC analysts simultaneously with automated client-side reconnect backoff.

## Executive Overview

**IntruShield NIDS** is an autonomous Network Intrusion Detection System and Security Operations Center (SOC) telemetry platform engineered by **Muhammad Haris**. It unifies the forensic deep-packet inspection capabilities of **Suricata 7** with an asynchronous **FastAPI** backend and an interactive **Next.js 14** web command center.

The platform provides small-to-medium security teams, homelab operators, and infrastructure engineers with instantaneous, visual threat monitoring without requiring complex SIEM infrastructure.

### Ingestion & Stream Processing
* **Engine**: Suricata 7 configured in AF_PACKET mode for high-throughput packet acquisition.
* **Log Pipeline**: Non-blocking `aiofiles` reader continuously tails `eve.json`. Incoming alerts undergo immediate JSON normalization, schema validation via Pydantic, and MaxMind GeoIP2 coordinate lookup for foreign IP addresses.
* **Deduplication Engine**: A sliding time-window memory buffer suppresses redundant signature notifications during active flood attacks, preserving database integrity and analyst focus.

### Real-Time Delivery & Visualization
* **WebSockets**: Custom connection manager in FastAPI maintains heartbeat pings, broadcasts structured alert payloads to all authenticated client sessions, and manages disconnect lifecycles.
* **Analyst Dashboard**: Next.js 14 App Router dashboard with Zustand state management. Displays live severity badges (Critical, High, Medium, Low), protocol breakdown (TCP, UDP, ICMP, DNS, TLS), and timeline activity histograms rendered via Recharts.
