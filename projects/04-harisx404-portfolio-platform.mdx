## Executive Overview

**Harisx404** is the digital flagship and production portfolio platform engineered by **Muhammad Haris**. Going far beyond a traditional static resume, it is an enterprise-grade full-stack web application built with **Next.js 15**, **React**, **TypeScript**, **Tailwind CSS**, and **Supabase PostgreSQL**.

It features an administrative CMS for dynamic publishing, real-time reactions and counters, an interactive Gemini AI conversation assistant, and a bespoke design language built from first principles.

### Core Engineering Innovations
* **App Router & Streaming**: Server Components fetch all projects, credentials, testimonials, and articles server-side. Skeleton loaders in `loading.tsx` stream instantly while database promises resolve in parallel.
* **Conversational AI Assistant**: Accessible portfolio assistant powered by Google Gemini, grounded with authoritative context on Haris's technical background, skillsets, and GitHub projects.
* **Production Admin Suite**: Dedicated `/admin` dashboard featuring an advanced MDX editor with live side-by-side rendering, draft/published workflow controls, and image management.
* **Performance & SEO**: Generates canonical URLs, RSS feeds, dynamic OpenGraph preview images via `@vercel/og`, and JSON-LD schema markup for rich search engine indexing.

## Design System & UX Standards

The visual design system adheres to modern web engineering aesthetics:
* **Tailored Color Palettes**: Ambient dark/light mode balance utilizing luminous neon accents for domain categories (Emerald for Full-Stack, Sky Blue for Cybersecurity, Violet for AI).
* **Typography Hierarchy**: JetBrains Mono for system terminals, Instrument Serif for prominent headings, and Outfit for accessible UI prose.
* **Zero Visual Glitch**: Frame-rate independent terminal decoding text animations, responsive bento grids, and interactive paper textures.
