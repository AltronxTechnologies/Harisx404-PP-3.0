# Phase 0 Approval Checklist

Give every item an explicit `APPROVED`, `DEFERRED`, or `N/A` disposition with a
rationale before implementation begins. These are gate decisions, not project
evidence-status values.

- [ ] Assignment due date recorded.
- [ ] Expected submission files recorded.
- [ ] Training environment and GPU recorded.
- [ ] YOLO implementation/version approved.
- [ ] Warehouse/industrial environment approved.
- [ ] Classes approved: person, forklift, hardhat, high-visibility vest.
- [ ] Data collection permission established.
- [ ] Roboflow workspace privacy established.
- [ ] External source licenses reviewed.
- [ ] Dataset target adjusted to available time and hardware.
- [ ] MVP event list approved, or events explicitly deferred to the portfolio.
- [ ] Explicit non-goals approved.
- [ ] Human-review wording approved.
- [ ] Code/model/data license decision recorded.
- [ ] Assignment-core versus portfolio-extension scope recorded.
- [ ] Subtree isolation and standalone release-repository approach approved.
- [ ] Detector validation/test protocol approved; event protocol approved only
  if events are in assignment scope, otherwise marked `DEFERRED`.
- [ ] Minimum per-class/source-group/slice targets recorded.

Approval record:

```text
Approved by:
Date:
Changes requested:
Evidence/link:
```
